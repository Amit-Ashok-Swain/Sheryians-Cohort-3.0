# 📖 About This Repository

Welcome to my **Sheryians Cohort 3.0 Learning Repository**.

This repository represents my complete learning journey throughout the **Sheryians Coding School Cohort 3.0**, where I explored modern frontend development by building projects, solving coding exercises, creating responsive websites, and developing real-world JavaScript and React applications.

Rather than serving as a collection of random assignments, this repository is structured as a **learning portfolio** that demonstrates my continuous growth from HTML fundamentals to building interactive applications using Vanilla JavaScript and React.

Throughout this journey, I focused on writing clean, maintainable code while strengthening my understanding of browser fundamentals, DOM manipulation, responsive UI development, and component-based thinking.
