# 📖 About This Repository

Welcome to my **Sheryians Cohort 3.0 Learning Repository**.

This repository represents my complete learning journey throughout the **Sheryians Coding School Cohort 3.0**, where I explored modern frontend development by building projects, solving coding exercises, creating responsive websites, and developing real-world JavaScript applications.
