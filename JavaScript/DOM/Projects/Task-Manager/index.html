Attributes vs Properties

HTML (Initial) 
                <input
                id="demoInput"
                value="Initial Value"
                >
Attribute (Original HTML Value) Initial Value
VS
JavaScript (After Change) 
        input.value =
        "Changed Value";
Property (Current Value) Changed Value
